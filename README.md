# Голосовой чат-интерфейс

Голосовой интерфейс в виде чат-мессенджера, где пользователь говорит, речь сразу преобразуется в текст и отображается как сообщение, а любая модель AI может отвечать на сообщения.

## Особенности

- 🎤 **Голосовой ввод** через Web Speech API
- 💬 **Чат-интерфейс** с сообщениями AI и пользователя
- 🎨 **Минималистичный дизайн** с использованием Pico CSS
- 📱 **Адаптивный интерфейс** для мобильных устройств
- ⚡ **Быстрая разработка** с минимальными кастомными CSS
- 🔄 **Имитация ответов AI** для демонстрации
- 🛠️ **Настройки модели AI** (GPT-4, Claude, Gemini, локальная)

## Технологии

- **HTML5** - семантическая разметка
- **Pico CSS** - минималистичный CSS фреймворк
- **JavaScript (ES6)** - логика приложения
- **Web Speech API** - распознавание речи
- **Font Awesome** - иконки

## Быстрый старт

### Вариант 1: Локальный запуск

1. Клонируйте или скачайте проект
2. Откройте файл `index.html` в браузере
3. Нажмите кнопку микрофона и говорите

### Вариант 2: Через локальный сервер (рекомендуется)

```bash
# Используя Python
python3 -m http.server 8000

# Используя Node.js (если установлен)
npx serve .
```

Затем откройте в браузере: `http://localhost:8000`

## Использование

### Голосовой режим
1. Убедитесь, что переключатель "Голосовой режим" включен
2. Нажмите кнопку "Говорите" (микрофон)
3. Говорите четко и разборчиво
4. Ваша речь будет преобразована в текст и отправлена в чат
5. AI ответит через 1-3 секунды

### Текстовый режим
1. Введите текст в поле ввода
2. Нажмите Enter или кнопку отправки
3. Сообщение появится в чате
4. AI ответит через 1-3 секунды

### Дополнительные функции
- **Очистка чата** - кнопка "Очистить"
- **Выбор модели AI** - выпадающий список в боковой панели
- **История диалогов** - боковая панель (заглушка)
- **Настройки** - кнопка настроек (заглушка)

## Требования к браузеру

- **Chrome 25+** (рекомендуется)
- **Edge 14+**
- **Safari 7+** (ограниченная поддержка)
- **Firefox** (требуется настройка)

**Примечание:** Web Speech API лучше всего работает в Chrome и Edge.

## GitFlow конфигурация

Проект подготовлен для использования GitFlow:

### Структура веток
- `main` - стабильная версия (продакшн)
- `develop` - основная ветка разработки

```bash

# Инициализация GitFlow

# Создание ветки для разработки интерфейса
git flow feature start voice-ui-pico

# После завершения работы над фичей
git flow feature finish voice-ui-pico
```

## Ограничения

1. **Web Speech API** работает только в поддерживаемых браузерах
2. **Распознавание речи** требует стабильного интернет-соединения
3. **Точность распознавания** зависит от качества микрофона и окружения
4. **AI ответы** в текущей версии - имитация

## Устранение неполадок

### Проблема: Микрофон не работает
**Решение:**
1. Проверьте разрешения браузера на доступ к микрофону
2. Убедитесь, что микрофон подключен и работает
3. Попробуйте другой браузер (Chrome/Edge)

### Проблема: Распознавание речи неточное
**Решение:**
1. Говорите четко и медленнее
2. Уменьшите фоновый шум
3. Проверьте настройки языка в браузере

### Проблема: AI не отвечает
**Решение:**
1. Проверьте подключение к интернету
2. Обновите страницу
3. Проверьте консоль браузера на ошибки
